      Introducción al Visor de Facturas
      
      
      
        
      Introducción: Este visor permite cargar, revisar y exportar facturas electrónicas (DTE) en formato JSON directamente desde su navegador, sin enviar datos a servidores externos.
      
        
      Qué hace: Guarda las facturas localmente, muestra un listado ordenado por fecha (del más antiguo al más reciente) y permite inspeccionar cada documento con sus datos completos, ítems, pagos y el JSON original.
      
        
      Opciones principales:
      
        
        
          
      • Subir uno o varios archivos JSON a la vez (control "Elegir archivo").
        • 
          
      • Buscar facturas por nombre del receptor, emisor o número usando la caja de búsqueda.
        • 
          
      • Filtrar la lista por mes para ver solo las facturas de un periodo.
        • 
          
      • Exportar el listado seleccionado como JSON con emisor, receptor, fecha, número, código, sello recibido y totales.
        • 
          
      • Limpiar todos los datos almacenados con el botón "Limpiar" (se solicita confirmación).
        • 
        
      
        
      Ejemplo de uso (rápido y claro): 1) Haga clic en "Elegir archivo" y seleccione un archivo JSON que contenga una factura (objeto con "identificacion", "emisor", "receptor" y "resumen"). 2) La factura aparecerá en la lista izquierda con fecha y total; use el filtro de mes si desea limitar la vista. 3) Haga clic en la factura para ver los detalles a la derecha (ítems, pagos, sello recibido y el JSON bruto). 4) Use "Exportar JSON" para descargar un resumen con los campos importantes o "Limpiar" para borrar todo (aparecerá una advertencia antes de eliminar).
